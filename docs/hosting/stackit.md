# Quickstart: STACKIT (aanbevolen)

> TODO — uit te schrijven zodra `src/relay` bestaat.

STACKIT is de aanbevolen hostingoptie voor de sync-relay: Europese eigenaar (Schwarz Gruppe), data uitsluitend in Duitsland/Oostenrijk, expliciet gepositioneerd als "soevereine cloud".

Voorziene opzet:
- **Rekencomponent:** Cloud Foundry PaaS of Container Engine (managed Kubernetes)
- **Objectopslag:** STACKIT Object Storage (S3-compatible), voor de versleutelde blobs

## Structuur (in te vullen)

1. Vereisten
2. Deploy-stappen (`cf push` of container-deploy)
3. Omgevingsvariabelen instellen
4. HTTPS/domein koppelen
5. Eerste apparaat verbinden
