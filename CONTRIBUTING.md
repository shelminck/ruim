# Bijdragen aan Ruim

Fijn dat je wilt bijdragen. Dit project staat nog in een vroege ontwikkelfase — lees eerst `CLAUDE.md` en `docs/architecture/` om de gemaakte keuzes te begrijpen voordat je een grote wijziging voorstelt.

## Voordat je begint

- Check `docs/backlog.md` en de open issues — misschien is jouw punt al genoteerd.
- Voor een architectuurwijziging: open eerst een issue of discussie. Grote keuzes horen als nieuwe ADR in `docs/architecture/decisions/`, niet als losse PR-beschrijving.
- Domeinlogica (Accounts, Categorization, Budgeting, Review, Planning) hoort in `src/pwa/`, in TypeScript. Geen dubbele implementatie in de .NET-projecten — zie ADR 0001.

## Pull requests

1. Fork de repository en maak een feature branch.
2. Houd PR's zo klein mogelijk en gericht op één onderwerp.
3. Beschrijf niet alleen *wat* er verandert, maar ook *waarom*.
4. Voeg tests toe waar zinvol.
5. Zorg dat bestaande tests en linting slagen voordat je een PR opent.

## Licentie

Door bij te dragen ga je ermee akkoord dat je bijdrage onder de AGPL-3.0-licentie van dit project valt (zie `LICENSE`).

## Gedragscode

Wees respectvol. Geen ruimte voor intimidatie, discriminatie of ander onbehoorlijk gedrag in issues, PR's of discussies.
