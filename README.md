# Ruim

Een lokaal-eerst huishoudboekje: potjes, automatische categorisatie van bankmutaties en een uitvallijst voor de twijfelgevallen. Werkt volledig offline op je eigen apparaat; delen met je gezin kan optioneel via versleutelde sync.

## Kernprincipe

Geen server nodig om te beginnen. Alle domeinlogica draait client-side; jouw data staat lokaal. Zie [`docs/architecture/architectuurplaat.html`](docs/architecture/architectuurplaat.html) voor het volledige overzicht.

## Status

Vroege ontwikkelfase — architectuur en v1-ontwerp zijn vastgelegd, code moet nog grotendeels gebouwd worden. Zie [`docs/backlog.md`](docs/backlog.md) voor openstaande beslissingen.
